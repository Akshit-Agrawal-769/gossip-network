How It Works

📡
01 · Local Discovery

Zero Internet Needed

Connect laptops and phones to any offline hotspot. Devices discover each other automatically via local mDNS with no router or cloud servers.

🫖
02 · Gossip Protocol

The Gossip Survives

Messages, photos, and voice notes replicate peer-to-peer via IPFS Pubsub. Even if the sender closes her laptop, the colony keeps the copy.

🛡️
03 · Content Fingerprints

Fake Forwards Caught

Every file gets a cryptographic fingerprint (CID) from its content. Alter a single word in an existing file and the network blocks the fake automatically.
