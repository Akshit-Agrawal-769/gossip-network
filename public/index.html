Aunty Network

“Indian aunties have run a zero-infrastructure, peer-to-peer information network for centuries. We built the digital version.”

When the Wi-Fi dies the night before an exam—or when there is no router or cloud in sight—Aunty Network bridges the gap between the people who have critical notes, photos, or voice updates and the people who need them. Information hops directly from laptop to laptop like colony gossip, and every file is cryptographically verified before it is forwarded.

I. Local Discovery

Zero Internet Needed

Connect laptops and phones to any offline hotspot. Nodes discover each other automatically via local mDNS—no cloud servers required.

II. Gossip Protocol

The Gossip Survives

Notes, photos, and voice clips spread peer-to-peer via IPFS Pubsub. Even if the original aunty closes her laptop, the colony keeps the copy.

III. Content Fingerprints

Fake Forwards Caught

Every file gets a content fingerprint (CID). If anyone alters a file and re-shares it under the same name, the colony blocks the fake automatically.
